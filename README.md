# 3DOF-Robotic-Arm-ModelA 
3-DOF robotic arm designed in Fusion 360 for automated washroom cleaning applications. The model includes full CAD assemblies and STEP files, featuring rotational and lifting joints optimized for scrubbing, spraying, and surface maintenance tasks in hygiene-focused environments.
